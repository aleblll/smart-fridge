## 2. Архитектурный стек и стандарты
- **Фреймворк:** React 19 + TypeScript + Vite[cite: 2].
- **Стилизация:** Tailwind CSS (только функциональные классы, строгая семантика)[cite: 2, 6].
- **Компоненты интерфейса:** Radix UI primitives / shadcn/ui + Vaul Drawer (нижние шторки)[cite: 6].
- **Интеграция с Telegram:** Библиотека `@telegram-apps/sdk-react` (типизированный SDK с поддержкой tree-shaking)[cite: 2].
- **Управление состоянием:** Zustand (локальное UI-состояние) + TanStack Query v5 (серверный кэш и синхронизация с Firebase)[cite: 2].

## 3. Обязанности и задачи
1. **Реализация интерфейса без «нейрослопа»:**
   - Верстка строго по канонам функционального минимализма (стилистика Linear, Cron, Apple Health)[cite: 6].
   - Полный запрет на декоративные фиолетовые градиенты, разноцветные тени и раздутые скругления[cite: 6].
   - Привязка системных цветов к нативным переменным Telegram (`var(--tg-theme-bg-color)`, `var(--tg-theme-text-color)`, etc.)[cite: 2, 6].
2. **Карточка продукта и расчет прогресса:**
   - Отображение относительного прогресс-бара срока годности по формуле:
     $$R = \max\left(0, \min\left(1, \frac{T_{\text{exp}} - T_{\text{current}}}{T_{\text{exp}} - T_{\text{start}}}\right)\right)$$
[cite: 6]
   - Динамическая цветовая индикация шкалы:
     - Зеленый (`emerald-500` / `rgba(16, 185, 129, 1)`): свежий продукт[cite: 6].
     - Янтарный (`amber-500` / `rgba(245, 158, 11, 1)`): осталось $\le 2$ дней[cite: 6].
     - Приглушенный красный (`rose-500` / `rgba(244, 63, 94, 1)`): истекает сегодня или просрочен[cite: 6].
3. **Конвейер добавления позиции за 3 секунды:**
   - Автоматический фокус в поле ввода при открытии нижней шторки (Vaul Drawer)[cite: 6].
   - Локальный мгновенный поиск по справочнику `src/data/foodPresets.json`[cite: 6, 7].
   - Генерация предиктивных чипов с готовым набором: название, зона хранения, срок по умолчанию, запас предупреждения[cite: 6, 7].
   - Сохранение записи в один тап по чипу[cite: 6].
4. **Нативная кинематика и физика Telegram:**
   - Вызов `Telegram.WebApp.disableVerticalSwipes()` при монтировании для исключения закрытия приложения при вертикальном скролле[cite: 2, 6].
   - Изоляция событий тача внутри шторки Vaul (`touch-action: none` на Drag Handle, `overscroll-behavior-y: contain` на контейнере скролла)[cite: 6].
   - Жесты свайпа строк инвентаря: свайп вправо — «Съедено», свайп влево — «В отходы»[cite: 6].
   - Тактильный отклик (Haptic Feedback) на системные пороги и действия[cite: 2, 6].
5. **Оптимистичный UI (Optimistic Updates with Rollback):**
   - Мгновенная модификация остатков на экране с вызовом `impactOccurred('light')`[cite: 2].
   - Асинхронная отправка мутации в Firebase[cite: 2].
   - В случае ошибки сети — откат состояния, `notificationOccurred('error')` и вывод Toast[cite: 2].

## 4. Карта тактильного отклика (Telegram Haptic Feedback API)
| Вызов SDK | Триггер в интерфейсе | Физический смысл |
|---|---|---|
| `impactOccurred('light')`[cite: 2, 6] | Нажатие степпера количества (+1 / -1), клик по табам («Холодильник / Морозилка / Шкаф»)[cite: 2, 6]. | Щелчок тумблера[cite: 6]. |
| `impactOccurred('medium')`[cite: 6] | Преодоление порога свайпа карточки (порог 48px)[cite: 6]. | Срабатывание механического фиксатора[cite: 6]. |
| `impactOccurred('heavy')`[cite: 6] | Долгое удержание (Long Press) карточки для контекстного меню[cite: 6]. | Отрыв от плоскости[cite: 6]. |
| `notificationOccurred('success')`[cite: 2, 6] | Успешное списание или добавление продукта[cite: 2, 6]. | Подтверждение операции[cite: 6]. |
| `notificationOccurred('error')`[cite: 2, 6] | Сбой записи в Firebase или сетевой таймаут[cite: 2]. | Отсечка при ошибке[cite: 6]. |

## 5. Ограничения и запреты
- **ЗАПРЕЩЕНО** модифицировать файлы в каталогах `01_Architecture/` и `02_Contracts/`[cite: 5]. Если контракт Firebase или схема пресетов не соответствуют задаче, задача блокируется (`status: blocked`) с комментарием Архитектору[cite: 5].
- **ЗАПРЕЩЕНО** подключать внешние веб-шрифты (Google Fonts). Используется нативный системный стек шрифтов: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`[cite: 2].
- **ЗАПРЕЩЕНО** использовать тяжелые десктопные пикеры дат. Выбор даты строится на пресетах (+1 день, +3 дня, +неделя) с компактным барабаном/нативным input type="date"[cite: 6].
- **ЗАПРЕЩЕНО** осуществлять сборку с объемом начального JS-чанка более 110 КБ[cite: 2]. Все второстепенные экраны (настройки, статистика) загружаются динамически через `React.lazy`[cite: 2].
