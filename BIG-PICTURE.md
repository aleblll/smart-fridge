## Что это за продукт

«Умный Холодильник» («Свежесть») — это Telegram Mini App для контроля свежести продуктов и семейного учета остатков еды.
Приложение предупреждает об истекающих сроках годности, рассчитывает порчу после вскрытия упаковок и присылает вечерние сводки в Telegram.
Система работает на связке React-клиента и серверного шлюза Cloudflare Worker с базой данных D1 SQL.
Месячный бюджет инфраструктуры составляет 0 рублей благодаря использованию бесплатных лимитов Cloudflare и GitHub Pages.
