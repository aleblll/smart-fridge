# ADR-003: Реализация контура ежедневных уведомлений через GitHub Actions Cron

## Контекст и проблематика
Приложению требуется ежедневно формировать и доставлять утренний дайджест продуктов, срок годности которых истекает сегодня или в ближайшие 1–2 дня. В архитектуре без постоянно работающего бэкенда (Zero-VPS) отсутствует серверный планировщик задач (Linux crontab / Celery Beat). Необходимо надежное, бесплатное и автономное решение для запуска ежедневной процедуры агрегации и рассылки.

## Рассмотренные альтернативы
1. **Cron-демон на арендованном сервере:**
   - *Плюсы:* Точность запуска секунда в секунду.
   - *Минусы:* Нарушает инвариант Zero-VPS, требует платной инфраструктуры.
2. **Внешние бесплатные cron-сервисы (cron-job.org / EasyCron):**
   - *Плюсы:* Простота триггера по HTTP.
   - *Минусы:* Требуют внешнего публичного вебхука/серверной функции, ненадежны, риски блокировки или сбоя стороннего сервиса.
3. **Google Cloud Functions / Cloud Scheduler:**
   - *Плюсы:* Нативная интеграция с Firebase.
   - *Минусы:* Требует привязки кредитной карты для активации тарифа Blaze в проектах Firebase; нарушает принцип 100% бесплатности без банковских карт.
4. **GitHub Actions Scheduled Workflow (`schedule: cron: '0 6 * * *'`):**
   - *Плюсы:* Полностью бесплатно (2000 минут в месяц включено в каждый аккаунт), секреты безопасно хранятся в GitHub Secrets, запуск окружения Node.js с полным доступом к сети и npm-пакетам.
   - *Минусы:* Допустимая задержка запуска до 10–20 минут в периоды высокой загрузки раннеров GitHub.

## Решение
Утвердить использование **GitHub Actions Scheduled Workflow** (`.github/workflows/notify.yml`) с ежедневным триггером в 06:00 UTC (09:00 МСК):
- Workflow запускает Node.js скрипт `scripts/notify.js`.
- Скрипт использует `firebase-admin` (через приватный ключ из секрета `FIREBASE_SERVICE_ACCOUNT`) для чтения состояния холодильников.
- Сообщения форматируются в виде компактного текста с MarkdownV2/HTML и отправляются методом `sendMessage` Telegram Bot API с токеном из секрета `TELEGRAM_BOT_TOKEN`.
- Для соблюдения правил Telegram Bot API скрипт использует встроенный ограничитель частоты (максимум 25–28 сообщений в секунду суммарно, не более 1 сообщения в секунду в один чат).

## Последствия
### Положительные:
- Решение абсолютно бесплатно и не требует ввода платежных данных.
- Полная автономность: репозиторий проекта содержит и код, и инфраструктуру запуска.
- Расход минут GitHub Actions составляет ~30–45 минут в месяц из доступных 2000 минут (менее 2.5% квоты).

### Отрицательные и компромиссы:
- Джиттер времени запуска: утренний дайджест может приходить в интервале между 09:00 и 09:20 локального времени, что является абсолютно комфортным окном для утреннего уведомления.
