# Детальная дорожная карта разработки TMA «Свежесть»

Архитектура: **Zero-VPS** (Cloudflare Edge Gateway + GitHub Pages + Telegram WebApp SDK + Telegram CloudStorage). Бюджет инфраструктуры: **0 руб/мес**.

---

## Фаза 1: Фундамент и клиентский UX (Спринт 1 — ВЫПОЛНЕНО ✅)

- [x] **TASK-001:** Инициализация React 19 + Vite + Tailwind CSS v4 + Telegram SDK (Бандл < 90 КБ gzipped).
- [x] **TASK-002:** Cloudflare Worker Edge Gateway (HMAC SHA-256 валидация `initData`, DTO Whitelist санитизация).
- [x] **TASK-003:** Датасет сроков хранения (122 базовых продукта по 11 категориям по СанПиН/USDA).
- [x] **TASK-004:** Нижняя шторка добавления продукта на `vaul`, предиктивный поиск, тактильность Haptics.
- [x] **TASK-005:** Скрипт утреннего дайджеста `scripts/notify.mjs` и workflow `.github/workflows/notify.yml` (рейт-лимит 25 msg/s).
- [x] **HOTFIX-001:** Редизайн интерфейса:
  - Категории продуктов (горизонтальный скролл 11 категорий).
  - Разделы: «Холодильник» (активные), «Съедено» (архив), «Утиль / Мусорка» (списанные).
  - Семейный доступ: модальное окно и генерация инвайт-ссылки.
  - Нативная синхронизация через `Telegram.WebApp.CloudStorage` (сквозной доступ с ПК и телефона).
  - Выбор произвольной даты: быстрые чипы (`+2д`, `+4д`, `+1нед`, `+2нед`, `+1мес`), степперы `+/- 1 день`, нативный выбор даты.
  - Sticky-кнопка сохранения (всегда видна, не перекрывается клавиатурой).
  - Встроенный экран «Диагностика и Логи» с экспортом в буфер.

---

## Фаза 2: Премиум UI (Inspo MCP) + Облачный мульти-юзер (Спринт 2)

**Цели:**
1. Полное искоренение «нейрослопа»: глубокий редизайн интерфейса через MCP `inspo` (референсы Linear, Apple Health, Cron), fluid-анимации, spring-кинематика карточек, swipe-to-action, субпиксельные микроконтрасты Zinc-950.
2. Автоматический контур верификации QA-субагентом после каждой сборки.
3. Многопользовательская семейная синхронизация между разными Telegram-аккаунтами через Cloudflare Edge KV/D1.

### 1. TASK-006: Редизайн UI на базе MCP `inspo` (Frontend Lead)
- **Мандат Inspo MCP:** Запрос референсов через `call_mcp_tool` (`inspo` -> `recommend`, `search_screens`, `find_components`, `get_reference_jsx`).
- **Анимации и кинематика:**
  - Плавные transitions при добавлении, перемещении между табами («Холодильник» / «Съедено» / «Утиль») и удалении карточек.
  - Spring-физика для Vaul Drawer.
  - Тактильный отклик Telegram Haptics на каждое действие.
  - Микродаунскейл (`active:scale-[0.985]`) при тапах.
- **Микроконтрасты:**
  - Базовый слой `#09090b` (Zinc-950), карточки `#121215` (Zinc-900), микрограни 1px `rgba(255, 255, 255, 0.08)`.
  - Цветовые акценты закреплены исключительно за статусом свежести продуктов.
- **Бандл:** Строгий лимит < 110 КБ gzipped.

### 2. TASK-007: Автоматизированный контур Post-Build QA (QA Inspector Subagent)
- Автоматический запуск субагента после каждой сборки фронтенда.
- Полная матрица проверки:
  - `npm run build` (TypeScript clean, 0 warnings).
  - `npm run lint` (ESLint 0 errors).
  - `npx vitest run` (100% passing tests).
  - Anti-Slop CSS аудит.
- Фиксация в отчете и коммит только при статусе `VERIFICATION: PASS`.

### 3. TASK-008: Семейная синхронизация Cloudflare Edge KV/D1 (Cloud Integrations)
- Настройка Cloudflare KV / D1 для персистентных общих пространств `fridge_spaces`.
- Эндпоинты `/api/sync/pull` и `/api/sync/push` для синхронизации нескольких Telegram-пользователей.
- Обработка `start_param` в TMA (`startapp=fridge_<ID>`) с автоматическим вступлением в семейный спейс.

## Фаза 3: Автоматический утренний дайджест (Спринт 3)

**Цель:** Автоматическая отправка уведомлений о продуктах, у которых подходит срок годности.

1. **TASK-009: Активация расписания GitHub Actions Cron**
   - Запуск `.github/workflows/notify.yml` каждый день в 06:00 UTC (09:00 МСК).
   - Выгрузка актуальных списков продуктов из Cloudflare Worker API.
   - Персонализированный дайджест каждому зарегистрированному пользователю бота.

2. **TASK-010: Индивидуальная настройка уведомлений в TMA**
   - Экран настроек в приложении: выбор времени получения пуша (например, 08:00, 10:00, 19:00).
   - Выбор за сколько дней предупреждать о скоропортящихся продуктах (от 1 до 5 дней).

---

## Фаза 4: Расширение каталога и умный ввод (Спринт 4)

**Цель:** Доведение базы продуктов до 300+ позиций и ввод продуктов без ручного набора.

1. **TASK-011: Интеграция расширенной базы Deep Research (300+ продуктов)**
   - Импорт валидированного отчета Deep Research с синонимами, советами по этилену и товарному соседству.
   - Нечеткий поиск (Fuzzy Search / Fuse.js) с исправлением опечаток (например, «малако» -> «Молоко»).

2. **TASK-012: Распознавание чеков (OCR) и штрихкодов**
   - Использование камеры смартфона (`Telegram.WebApp.showScanQrPopup` или BarcodeDetector API) для мгновенного считывания EAN-13 штрихкодов с упаковок.
   - Поиск по открытой базе штрихкодов продуктов (Open Food Facts API).
